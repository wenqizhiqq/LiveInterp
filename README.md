# 离线同传机器人界面解读（约1000字）
这是一款**完全离线本地运行**的中英同传翻译桌面软件，适配会议实时翻译场景，整套方案全部在本机完成语音识别、翻译、人声断句、朗读输出，不需要联网，不存在会议对话上传云端泄密的风险，非常适合技术研讨会、涉密内部会议，也能嵌入你正在搭建的本地WenAgent智能体体系，作为语音交互模块。

界面顶部标题为“同传机器人·离线”，状态栏展示核心状态：**监听中·等待说话**，当前处于模拟测试模式，麦克风输入被旁路，使用内置语音素材做无声仿真验证，不会拾取外界声音，也不会对外播放音频，方便开发调试，避免测试阶段干扰环境。软件集成了自动中英互译、人声打断、声纹区分说话人、知识库术语库、模拟测试等全套能力。底部状态栏能看到底层开源组件：Vosk负责离线语音识别ASR，OPUS-MT作为机器翻译NMT引擎，内置46121句对知识库、近十万条专业术语，会议里的行业词汇可以提前导入术语库，保证专业名词翻译一致性。

中间对话区域展示模拟会议的翻译流程，支持区分两个说话人，双向互译。说话人1中文转英文，输入“欢迎参加今天的会议”，实时输出译文`Welcome to today's meeting.`，状态标记为**被打断**，代表检测到新的人声输入，立刻终止上一句朗读，做到同传里的边听边译、随时打断；字幕延迟1.9秒，首音2.1秒，属于实时同传的低延迟水平。第二条是英文转中文，输入`please stop for a moment`，译文输出“请停一下”，状态标记**已完成**，字幕2.1秒，首音2.2秒。这种打断机制是离线同传的核心难点，很多开源语音翻译工具只能等一句话说完再翻译，而这个软件可以识别说话人中途停顿、新的语音切入，动态截断朗读输出，贴近真人同传的交互逻辑。

软件内置一套控制台指令体系，输入`/help`查看全部命令；`/devices`查看麦克风设备列表；`/mic`切换麦克风片段；`/sim`开启或者关闭无声模拟演示。模拟测试模式非常适合开发调试：不需要外接麦克风，使用内置语音素材跑完整流程，验证ASR识别、翻译、断句、朗读全链路，不会产生外部噪音，迭代算法的时候很方便。

底层技术栈全部是开源离线组件：Vosk做本地语音识别，OPUS-MT做翻译，搭配自定义的声纹分离、人声断句模块。术语库功能是面向工业、技术会议的实用能力，可以提前导入行业专有名词，比如自动化、机器人、半导体相关词汇，防止模型直译出错，保证专业会议翻译准确度。

从你的整体项目视角来看，这个离线语音同传模块可以直接接入WenAgent本地AI Agent。作为前端语音感知层：麦克风采集语音，离线ASR转文字，经过同传翻译，交给本地大模型做任务理解；Agent完成思考、规划之后，再把文本交给TTS朗读输出，形成完整的本地语音交互闭环。整套链路全程不上云，会议内容、指令、工程资料全部留在本机，解决最关键的数据泄密风险。

目前这套原型已经打通语音识别、双向翻译、人声打断、说话人区分，已经满足基础会议同传需求。后续优化方向：一是优化长句断句算法，进一步压缩延迟；二是扩充知识库，导入自动化、机器人领域术语；三是和WenAgent联动，让Agent听懂语音指令，直接操控机械臂、自动化设备，实现语音驱动的具身智能。
